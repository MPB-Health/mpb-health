# @mpbhealth/form-embed

Embeddable CRM web form component for external sites.

## Installation

```bash
pnpm add @mpbhealth/form-embed
```

Built with tsup. Output in `dist/`.

## Usage

### React

```tsx
import { MPBFormEmbed } from "@mpbhealth/form-embed";

function ContactPage() {
  return <MPBFormEmbed formId="abc123" onSubmit={(data) => console.log(data)} />;
}
```

### Vanilla JS

```html
<div id="mpb-form"></div>
<script src="https://cdn.example.com/mpb-form-embed.js"></script>
<script>
  MPBForms.renderForm({ target: "#mpb-form", formId: "abc123" });
</script>
```

## API Reference

- `MPBFormEmbed` — React component for embedding forms
- `renderForm(options)` — vanilla JS render function for non-React sites
- Type exports for form configuration and submission data

## Apps Using This Package

Not a direct app dependency. Embed code is generated by the CRM form builder for use on external websites.
